# Windows high-contrast check (about 15 minutes)

The page passed a simulation of Windows high contrast on 19 November 2026. This check
confirms it on Windows itself, where each contrast theme picks its own colors. Open this
file on the Windows computer, so you can follow it there.

## Set up

1. Open the page in **Microsoft Edge** or **Chrome**:
   https://davidpetry-cloud.github.io/two-forecasts-one-sky/
2. Turn on a contrast theme: **Settings → Accessibility → Contrast themes**, choose
   **Night sky**, then **Apply**. (Shortcut: left Alt + left Shift + Print Screen turns it
   on and off.)
3. Go through the list below once with **Night sky** (dark), then once with **Desert**
   (light).
4. To capture a problem: **Windows + Shift + S**, then drag around it.

## What to look at

For each item, the question is: **can you see it, and can you tell the states apart?**

| # | Where | Check |
|---|---|---|
| 1 | The opening | The "Prototype" label, the °F/°C switch (which one is on?), the theme button and "Start with a case" all have visible edges. |
| 2 | Keyboard | Press **Tab** through the page. The focus ring is visible on every button, choice and link. |
| 3 | Step 01 | The chosen place, evening and length are clearly marked, not just a different color. |
| 4 | Steps 02 and 03 | Guess, then "Show what happened". In the drawing, the circle (AI), square (physics) and diamond (measured) are all visible. The table has lines. |
| 5 | "And rain?" | The rain table under the case is readable. |
| 6 | The bigger picture | The dot plot shows circles and squares. In "Evening by evening", select the chart and press the right arrow: the line and the readout box both show. |
| 7 | By place | The map outline and the six pins show. Choose a place: the chosen button is clearly marked. |
| 8 | Step 04 | Chosen answers are marked; "your rule" is marked in the "Every rule" table; the "Your rule so far" bar at the bottom has a visible top edge. |
| 9 | Search | Type "rain": the matching letters are marked in the results. |
| 10 | Lesson plan | Open "For educators" in the footer: the "Print this plan" button and the back link are visible. |

## Report back

For anything that fails, note the item number, the theme (Night sky or Desert), and attach
the screenshot. If everything passes, just say "Windows check passed", and the accessibility
statement on the page will be updated to say so.
